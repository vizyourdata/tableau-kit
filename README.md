# Tableau Kit

**A practical toolkit for technical Tableau users.**  
Scripts, workflows, and automation patterns that make Tableau faster, cleaner, and more powerful.

---

## 🔧 What’s Inside

Tableau Kit is built for developers, analysts, and data teams who want to go beyond dragging and dropping. Inside, you'll find:

- **Version Control Workflows** – Git setups that actually work for Tableau
- **Automation Scripts** – API pipelines, Hyper publishing, and more
- **Performance Fixes** – Refactoring dashboards, optimizing extracts
- **Course Resources** – Companion files for live courses and walkthroughs

---

## 🚀 Who It’s For

- Data professionals managing messy Tableau environments  
- Developers integrating Tableau into larger data stacks  
- Anyone tired of manual work, dashboard bloat, or brittle processes
